User Management Information
User Data Overview

The Game Night Bot manages user profiles, preferences, and game interests across Discord servers. User data includes:

  • Profile Information: Display names, timezones, and notification preferences
  • Game Interests: Games users want to be notified about with interest levels
  • Availability: Weekly availability schedules for event planning
  • Statistics: Event attendance, RSVP history, and participation metrics
Privacy & Data Protection

All user data is stored securely and users can:

  • Export their data using the /profile command
  • Update their preferences at any time
  • Request data deletion through Discord server administrators
User Commands

/profile - View and manage profile

/timezone - Set timezone

/availability - Manage availability

/notifications - Configure notifications

/games-add - Add game interests

/games-list - View game interests
